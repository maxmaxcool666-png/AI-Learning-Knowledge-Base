## 個人心得

### 1. 最大的學習收穫

這次學習 GitHub Pages，讓我知道如何將原本只能在自己電腦上觀看的網站部署到網路上，讓其他人也能透過公開網址瀏覽網站。

### 2. 學習過程中遇到的困難

我覺得最困難的部分是 GitHub Pages 的部署設定。因為 GitHub 網站目前提供的使用者介面是英文，在設定過程中，我主要透過瀏覽器內建的翻譯功能來理解介面內容，再配合 AI 提供的操作步驟，一步一步完成設定。

### 3. 未來的應用方向

未來我希望將 GitHub 運用在持續記錄與整理自己的學習成果及學習過程上，無論是需要私人保存的內容，或是希望公開展示、方便其他人查看的成果，都能依照不同需求進行管理。

此外，我也希望能運用 GitHub Pages 來展示學校專題或其他靜態網站，讓老師或其他人可以直接透過網站網址瀏覽我的作品，更方便地了解我的學習成果與實作內容。
